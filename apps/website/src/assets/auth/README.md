# Login-provider artwork

`google.png` is the unmodified Google "G" supplied with Google's sign-in branding guidance.

- [Original asset](https://developers.google.com/static/identity/images/g-logo.png)
- [Sign-in branding requirements](https://developers.google.com/identity/branding-guidelines)
- [Google trademark guidance](https://about.google/brand-resource-center/rules/)

This is third-party brand artwork, not artwork licensed by this repository under Apache-2.0. Follow Google's applicable branding terms when using the asset.

The sign-in guidance requires the supplied color "G" and prohibits monochrome versions. Preserve its colors and proportions, and use it to identify Google sign-in.
